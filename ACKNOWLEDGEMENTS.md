# Acknowledgements

## Seumas and od6s

Tyfusius wrote D6 System Second Edition independently from scratch. Seumas's
od6s system provided valuable ideas and reference while Tyfusius learned how to
organize Foundry sheets and documents, structure roll workflows, and make
OpenD6 practical to use in Foundry.

Tyfusius used OpenD6 Next as a separate, temporary learning project while
porting and adapting od6s concepts for ApplicationV2. D6 System Second Edition
then began as a new TypeScript-heavy implementation with a different
architecture. OpenD6 Next is a separate project and is outside this
repository's licensing.

This repository does not redistribute od6s source code.

## Darth Banjo and the Star Wars D6 Essential Companion

The private Star Wars D6 companion adapts and converts material from
[The Essential Companion to Star Wars D6 on OpenD6 Space](https://github.com/DarthBanjo/starwarsd6-essentialcompanion-od6s),
created by **Darth Banjo**. That project provided the original Foundry module,
compendium organization, document identifiers, macros, artwork, and source
material from which the private D6 System Second Edition companion conversion
was developed.

Darth Banjo's upstream attribution and licensing notices remain applicable to
material originating in that project. The private companion preserves those
notices in its `THIRD-PARTY-NOTICES.md`; this acknowledgement does not imply
endorsement by Darth Banjo or grant rights to Star Wars intellectual property.
