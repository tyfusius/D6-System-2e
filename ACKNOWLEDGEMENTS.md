# Acknowledgements

## Seumas and od6s

Tyfusius wrote D6 System Second Edition independently from scratch. Seumas's
od6s system provided valuable ideas and reference while Tyfusius learned how to
organize Foundry sheets and documents, structure roll workflows, and make
OpenD6 practical to use in Foundry.

Tyfusius used OpenD6 Next as a separate, temporary learning project while
porting and adapting od6s concepts for ApplicationV2. D6 System Second Edition
then began as a new TypeScript-heavy implementation with a different
architecture. OpenD6 Next is a separate project and is outside this
repository's licensing.

This repository does not redistribute od6s source code.
