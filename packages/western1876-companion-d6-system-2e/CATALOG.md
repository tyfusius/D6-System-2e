# 1876 current working attributes and skills

This bounded setup follows the user's request to use the current 1876 working rules. The source is `drafts/draft-01/1876-RULEBOOK-DRAFT-01.md`, Chapters 2, 3 and 5, with Design Ledger decisions 1876-074, 1876-113 and 1876-116. Exact source SHA-256 hashes and independently extracted skill headings/mappings are in `catalog-provenance.json`. The Markdown manuscript has no printed page numbers; chapter and section references are used without fabricated pages.

The six-attribute architecture remains provisional in the manuscript, including Demolition under Knowledge. Decision 113 accepts explanatory prose, not final mechanical acceptance of that architecture. Decision 116 accepts the expansion request and records an untested candidate implementation; Blowguns is elective. This setup does not implement the complete candidate rulebook.

The Setting Profile retains the system's full 17-label vocabulary for normalization; vocabulary does not activate attributes. The existing attribute contract has no description field, so these explanations are recorded here for the central manual rather than adding a private field.

The manuscript's individual starting range of 2D–4D, its 6/6/3/6 skill-pip shares, per-skill caps and career/upbringing permissions remain table procedures unless already supported by the base system. This catalogue adds no automatic package grants or custom allocation enforcement.

## Skill coverage and professional scope

The 36 core skill families become 43 concrete skills when Handling is expanded into eight fields. Elective Blowguns makes 44. Reflexes has Dodge, Brawling, Melee, Riding, Acrobatics and Stealth. Coordination has Firearms, Archery, Blowguns, Throwing, Sleight, Lockwork and Driving. Physique has Athletics, Lifting, Stamina and Swimming. Knowledge has Demolition, Medicine, Gunsmithing, Craft, Scholarship, Law and Business. Perception has Notice, Search, Tracking, Survival, Investigation and Gambling. Presence has Persuasion, Deception, Intimidation, Command, Willpower, Performance and the eight Handling fields.

Handling: Horses, Dogs, Cattle, Sheep, Pigs, Mules, Falconry and Poultry are independent full skills based on Presence. There is no universal Handling parent and no bonus specialization. Each improved total includes Presence once. Riding remains separate. Ordinary uncertain attempts may use unimproved Presence; demanding training needs the relevant knowledge, and veterinary procedures need appropriately trained Medicine. Another agreed animal field can be added as an ordinary custom skill.

Medicine preserves household care, midwifery, surgery, veterinary work and other recorded scopes without granting all of them to every practitioner. Gunsmithing, Lockwork, Craft and Demolition likewise require the actual learned methods and equipment described in the manuscript. These permission distinctions use descriptions, not the system's `advanced` training category, which would change base-pool and advancement behavior. All 44 entries use standard training; no psionic or supernatural category is added.

Blowguns uses Coordination and an existing background familiarity for access. Existing personal skill pips provide any starting improvement within the manuscript caps. It adds no free training, extra familiarity, altered package, ancestry entitlement or half-price specialization. It remains an elective choice, with ordinary improvement costs and appropriate instruction during play.

## Difficulty and presentation

The working difficulties are Easy 10, Moderate 15, Difficult 20, Very Difficult 25 and Exceptional 30. The existing Very Easy support tier remains 5 for an uncertain hurried, impaired or barely familiar attempt. Routine competent work normally succeeds without rolling. Existing tier IDs remain unchanged; the top `heroic` ID displays Exceptional.

Skill images reference semantically matched icons already shipped with Foundry 14.367. No icon files are copied, generated or fetched. Mules use a generic animal-track symbol rather than a mislabeled horse image. The prior local logo, display font, palette and readable body typography are unchanged.

Enabling the companion registers contributions only. Explicit Campaign Setup selection activates the paired profiles. The base system owns genre binding, catalog-based character workflows and fallback behavior. This contribution does not create Items or compendiums, bulk-edit Actors, grant career packages, or implement additional combat, dynamite, horse or mental-wound rules.
